# ARN Dataset Documentation & Provenance

## Provenance and Generation Protocol

The primary dataset (`data/raw/aether_orchestrator_dataset.jsonl`, 5,000 samples) is **fully synthetic and template-generated** using pure Python programmatic generation (`ARN/scripts/template_generator.py`) with a fixed random seed (`seed=42`).

### Generation Details:
- **Synthetic Logic:** Combinatorial Python generators define entity slots (contacts, apps, URLs, smart devices, search queries), speech disfluencies ("actually wait, make that..."), colloquial phrasing, and multi-tool compound operations (22.6% multi-tool chains).
- **Rule-Based Affixes Only:** All conversational variations use deterministic prefix/suffix tables and slot substitutions.
- **NO LLM Paraphrase:** No samples in this dataset were generated by, paraphrased by, or filtered by Large Language Models (LLMs).
- **Substring Alignment Enforcement:** Every entity argument value is programmatically asserted to be an exact substring of the user utterance (`str_val in user_prompt`).

## Historical Augmented File
The legacy file `data/raw/aether_orchestrator_dataset_augmented.jsonl` (13,798 samples) was created during preliminary exploration of a 16-tool schema using rule-based prefix/suffix injections. It contains 0 samples for `browser_task` and `browser_open_and_interact`. It is archived and **not used** for training or evaluating the 18-tool model.

## Frozen Splits & Cryptographic Manifest

### Evaluability & Exception List
- Because `open_url` has only 1 template cluster across the entire 5,000-sample dataset (`"open <URL> in the browser"`), strict group-disjoint partitioning requires that cluster to reside in `train`.
- As a result, `open_url` has 0 validation and 0 test samples.
- **17 of the 18 tools** are evaluable in validation and test. `open_url` is explicitly documented as an exception and marked as `[insufficient support]` in evaluation reports.
